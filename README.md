## Overview

This repository accompanies a preprint on off-grid sparse Bayesian channel estimation for AFDM. The proposed BG-SBL method combines path-support learning with continuous-Doppler dictionary refinement.

## Paper

The manuscript is available in this repository as `BG-SBL_Liu_Zhaoyang.pdf`.

Archived preprint and DOI: [https://doi.org/10.5281/zenodo.23407426]
